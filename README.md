# Page 24 - Author Dashboard

Standalone client interface for Page 24 authors to manage their books, view analytics, update profiles, and compose web content.

## Features
- Dashboard & My Book: Overview of published works and quick actions.
- **Publishing Suite**: Multi-format support (PDF and Web/HTML books) with auto-locking rules.
- **Web Studio**: Chapter editor for web-native books.
- **Sales & Royalties**: Real-time sales stats, revenue breakdown, and EcoCash balance tracking.
- **Author Profile**: KYC and payout detail management.

## Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript (ES6 Vanilla)
- **API**: Express / Node.js Backend Integration
